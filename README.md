# 🚀 Priyansh Patel - Personal Portfolio

A sleek, modern, and highly interactive personal portfolio built with React.js, Tailwind CSS, and Framer Motion. This project showcases my skills, projects, and achievements using a futuristic, terminal-inspired design.

## ✨ Features

- **Futuristic UI**: Dark mode, glassmorphism, galaxy particle backgrounds, and neon glowing accents.
- **Interactive Terminal**: A fully functional pseudo-terminal to explore my stats and configure the experience.
- **3D Tilt Cards**: Engaging, physics-based hover effects on project cards using Framer Motion.
- **Dynamic Content**: Sections for Skills, Featured Projects, Core Clones, Games, Hackathon experiences, and Certifications.
- **Responsive Design**: Flawless experience across desktops, tablets, and smartphones.
- **Smooth Animations**: Page transitions, scroll reveals, and micro-interactions powered by Framer Motion.
- **Custom Cursor**: A slick trailing cursor effect that adds life to navigation.

## 🛠️ Tech Stack

- **Frontend Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Form Handling**: [EmailJS](https://www.emailjs.com/)

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have Node.js and npm installed on your device.

### 1. Clone the repository
```bash
git clone https://github.com/PriyanshCG/port.git
```

### 2. Navigate to the project directory
```bash
cd port
```

### 3. Install dependencies
```bash
npm install
```

### 4. Start the development server
```bash
npm run dev
```

### 5. Open in browser
Open `http://localhost:5173` to view it in the browser.

## 📂 Project Structure

- `/src/components` - Houses all the modular React components (Hero, About, Projects, Terminal, Skills, etc.)
- `/src/assets` - Stores static assets, images, and brand materials.
- `/src/index.css` - Global CSS configurations, Tailwind directives, and custom animation keyframes.
